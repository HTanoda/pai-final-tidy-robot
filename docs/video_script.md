# デモ動画の構成・台本・字幕案

YouTube タイトル：**PAI最終課題＿hirokitanoda**
目標尺：**2分00秒〜2分40秒**（規定は1〜3分。3分を超えたら2倍速にして明記する）

本編は `python -m tidybot.demo` が生成する合成動画（`videos/demo.mp4`）をそのまま使う想定です。
画面には「指示・ロボットの返事・状況・AI認識・LLMの計画」が焼き込まれるので、
字幕を別に付けなくても内容が伝わります。下の「ナレーション」は任意で、
入れる場合は動画編集ソフトで音声として重ねるか、YouTube の字幕（SRT）として付けます。

### 見せ場（評価の加点要素との対応）

- **創造性**：カテゴリ名を言わない日常的な指示（「お腹がすいた」「飲み終わった」）を解釈する。存在しない物の指示に正しく「できません」と返す。
- **技術力**：合成データ＋ドメインランダム化で学習した視覚モデル、深度からの3D把持点推定、逆運動学、動作後の視覚確認と再試行。
- **実用性**：家庭やオフィスで「ざっくり頼む」片付けの自動化。
- **表現力**：AIの視界とLLMの計画を同じ画面に並べ、何を考えているかを可視化。

## ナレーション原稿（読み上げ用・約60秒分）

> 言葉で頼むと机を片付けてくれるロボットアームを作りました。
> 右上はロボットの視界です。シミュレータで自動生成した画像で学習したモデルが、8種類の物を見分けています。
> 「お腹がすいたから、食べられるものを集めておいて」。果物という言葉はありませんが、大規模言語モデルが、りんご・みかん・バナナを選んで手順を立てます。
> 運んだあとは、もう一度カメラで見て、箱に入ったかを確かめます。つかみ損ねたら、見直してやり直します。
> 机の上にないぬいぐるみを頼むと、「見当たりません」と答えて動きません。
> 赤い積み木とりんごのように色が似た物も、形で見分けて片付けます。
> 視覚は自前学習のU-Net、計画はClaude、制御は逆運動学と視覚フィードバックです。コードはGitHubで公開しています。

ナレーションなしでも合格要件は満たします。入れない場合は BGM も不要です（著作権の確認が要らなくなります）。

YouTube Studio の「字幕」からアップロードします。時刻は実際の動画に合わせて直してください。

