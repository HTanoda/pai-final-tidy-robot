### 見せ場（評価の加点要素との対応）

- **創造性**：カテゴリ名を言わない日常的な指示（「お腹がすいた」「飲み終わった」）を解釈する。存在しない物の指示には動かずに理由と代案を返す。
- **技術力**：合成データ＋ドメインランダム化で学習した視覚モデル（val mIoU 0.896）、深度からの3D把持点推定、逆運動学、動作後の視覚確認と再試行。
- **実用性**：家庭やオフィスで「ざっくり頼む」片付けの自動化。
- **表現力**：AIの視界とLLMの計画を同じ画面に並べ、何を考えているかを可視化。

## YouTube 字幕（SRT）

`docs/subtitles_ja.srt` を YouTube Studio の「字幕 → 追加 → ファイルをアップロード（タイミングあり）」で付けます。
時刻は本番動画（125.2秒）に合わせ済みです。YouTube の字幕は画面下に出て焼き込みの「指示」欄と重なるので、
字幕は補足として任意で付けてください（視聴者が字幕をオフにすれば消えます）。

## YouTube 概要欄テンプレート

```text
Physical AI 応用編1 最終課題（omnicampus: hirokitanoda）

「言葉で頼める片付けロボット」
日本語のあいまいな指示（例：「お腹がすいたから、食べられるものを集めておいて」）を受けて、
ロボットアーム Franka Panda が机の上の物を認識し、適切な箱へ片付けます（MuJoCo シミュレーション）。

・視覚：シミュレータで自動生成した合成画像で学習した U-Net（8種類の物体のセグメンテーション）
・計画：Claude（大規模言語モデル）による指示の解釈と手順の生成
・制御：逆運動学によるピック&プレース、動作後の視覚確認と再試行

再生速度：等倍（1倍速）・2分05秒
コード：https://github.com/HTanoda/pai-final-tidy-robot

0:00 指示1「お腹がすいたから、食べられるものを集めておいて」
0:44 指示2「飲み終わったものはリサイクルに出しておいて」
1:10 指示3「ぬいぐるみもしまっておいて」（存在しない物）
1:24 指示4「最後に、おもちゃを片付けて」
```

最後の4行は YouTube のチャプター（先頭が 0:00、各10秒以上の条件を満たす）になります。

2倍速にした場合は「再生速度：等倍」を「**2倍速で再生しています**」に変え、`scenarios/demo.json` の
`subtitle` の「動画は等倍速です」も「動画は2倍速です」に変えて動画を作り直してください（動画内と概要欄の両方に書くのが安全です）。
